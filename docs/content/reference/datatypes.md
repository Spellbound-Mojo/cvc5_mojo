# Datatypes

You declare an algebraic datatype with `DatatypeDecl` and
`DatatypeConstructorDecl`, and the term manager turns the declaration into
a sort. `Datatype`, `DatatypeConstructor`, and `DatatypeSelector` describe
the result.
